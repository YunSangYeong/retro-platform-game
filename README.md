# Moonleaf Run · 달잎 탐험

독창적인 탐험가와 초록 숲을 배경으로 하는 8비트 스타일 브라우저 플랫폼 게임. Phaser 3 / JavaScript / Vite로 구현한 단일 스테이지 프로토타입입니다. 서버와 DB가 필요 없습니다.

## 실행

Node.js 22 이상 권장.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소를 브라우저로 엽니다. 시작 화면을 누르거나 Z, Space, Enter로 시작합니다.

```sh
npm test
npm run build
npm run preview
```

`dist/`가 배포 결과물입니다. `npm test`는 스테이지 구조 검증이며 실제 플레이 검증은 브라우저에서 수행합니다.

## 조작

| 기능     | PC                                      | 모바일    |
| -------- | --------------------------------------- | --------- |
| 이동     | ← / →                                   | ◀ / ▶   |
| 점프     | Z / Space, 길게 누르면 높이 증가        | JUMP      |
| 달리기   | X / Shift                               | RUN       |
| 일시정지 | P 또는 상단 버튼                        | 상단 버튼 |
| 음소거   | M 또는 SOUND                            | SOUND     |
| 재시작   | 게임오버/클리어 후 Enter 또는 화면 클릭 | 화면 터치 |

모바일 버튼은 화면 아래에 배치되며 동시 입력을 지원합니다. 창이 포커스를 잃으면 일시정지합니다. 구덩이와 적을 피해 오른쪽 깃발까지 이동하세요. 적은 위에서 밟으면 제거되며, 물음표 블록을 아래에서 치면 코인을 얻습니다. 피격/추락 시 목숨을 잃고 시작 지점에서 재도전합니다. 코인과 점수는 유지됩니다. 시간 초과 시 게임오버입니다.

## GitHub Pages

저장소 Settings → Pages → Source를 **GitHub Actions**로 선택하고 `main`에 푸시하거나 Deploy GitHub Pages 워크플로를 수동 실행합니다. 워크플로가 테스트와 빌드를 수행하고 `dist`를 배포합니다. 상대 경로(`base: './'`)로 사용자/프로젝트 Pages 모두 지원합니다. 이 작업 자체가 원격 푸시나 배포를 실행하지는 않습니다.

## 구조와 에셋

- `src/main.js`: 장면, 절차적 픽셀 그림, 물리, 입력, UI
- `src/level.js`: 독자 설계 스테이지 데이터
- `src/audio.js`: Web Audio 오리지널 멜로디와 효과음
- `src/style.css`: 반응형 외부 프레임과 모바일 컨트롤

모든 그림과 음악은 이 프로젝트를 위해 코드로 생성했으며 외부 이미지·폰트·음원 파일이 없습니다. 원작 캐릭터 및 곡을 사용하지 않습니다. Phaser는 MIT 라이선스이며 의존성 라이선스는 각 패키지를 따릅니다. 프로젝트의 독창적 코드/에셋 사용 조건은 LICENSE를 참고하세요.

내부 해상도는 256×240이며 공간이 허용되면 정수배로 확대합니다. 60FPS를 목표로 하지만 기기 성능에 따라 달라집니다. 첫 스테이지에 집중하며 추가 스테이지나 저장 기능은 포함하지 않습니다.

## 브라우저 회귀 검증

개발 서버를 실행한 상태에서 `npm run test:browser`를 실행합니다. 시스템 Chromium 기본 경로는 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 변경할 수 있습니다. Playwright가 제공하는 Chromium을 쓰려면 설치 후 해당 실행 파일 경로를 지정하세요. `browser.mjs`는 이동, 점프 높이, 충돌, 코인 블록, 적 밟기, 피격과 상태 전환을 검사합니다. `mobile.mjs`는 동시 터치를 검사하며, `traverse.mjs`는 위치를 순간 이동하거나 목숨을 조작하지 않고 입력으로 첫 스테이지를 통과합니다. 테스트의 진단용 장면 참조는 `window.__gameScene`에 노출됩니다. `GAME_URL`은 `browser.mjs`의 대상 주소를 변경할 수 있습니다.
